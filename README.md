# ACBRAIN – AI Landing Page

A modern, responsive AI landing page UI for ACBRAIN, an AI-powered chat application concept. The design features a dark-themed interface, vibrant gradient elements, an AI-inspired hero section, and an interactive sign-in dialog box.

## 🚀 Features

- Modern and visually appealing AI landing page design.
- Fully responsive layout for different screen sizes.
- Dark-themed UI with gradient accents and visual effects.
- Navigation menu with Features, Pricing, How to Use, and Roadmap sections.
- Interactive Sign In button that opens a sign-in dialog box.
- Clean layout with minimal JavaScript.

## 🛠️ Technologies Used

- **HTML5** – Page structure and content.
- **CSS3** – Styling, layouts, gradients, animations, and responsive design.
- **JavaScript** – Sign-in dialog box interaction.

## 📸 Project Preview

The landing page features a modern AI-inspired design with a dark background, colorful gradients, and a visually engaging hero section.

## ⚙️ Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/arpana23/ai-landing-page.git
   ```

2. Navigate to the project folder:

   ```bash
   cd ai-landing-page

   ```

3. Open `index.html` in your browser.

## 📌 Project Scope

This project focuses on frontend UI development and responsiveness. It does not include backend integration, database connectivity, or actual authentication functionality. The sign-in dialog box is implemented for UI interaction purposes only.

## 👩‍💻 Author

Developed as a frontend UI project using HTML5, CSS3, and JavaScript.
